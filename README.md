## About

This workspace focuses on end-to-end supervised learning tasks using the provided training and test datasets. The primary deliverables are notebooks and a submission CSV that match the expected format.

		- test.csv
		- sample_submission.csv
		- submission.csv

## Getting Started

1. Open the notebooks in [Midterms/](Midterms/).
2. Ensure your Python environment includes `pandas`, `scikit-learn`, `matplotlib`, `seaborn`, and `statsmodels`.
3. Run the cells in order, starting from the data loading section.

## Usage

- Train a model using the training data.
- Evaluate using RMSE.
- Generate predictions for the test data.
- Export `submission.csv` that matches the sample submission format.
